# Carnet PTES

Le carnet de pentest de WaridoSann. Six phases PTES, des commandes d’audit copiables et des références pour les cours et les labos.

## Ouvrir le carnet

Télécharge le dépôt, décompresse l’archive et ouvre `index.html`. La navigation et les commandes fonctionnent sans connexion. Les références externes s’ouvrent avec une connexion. Aucun outil de compilation n’est nécessaire.

## Publier sur GitHub Pages

Dans **Settings → Pages**, choisis **Deploy from a branch**, puis **main** et **/(root)**. Enregistre. GitHub affichera l’adresse une fois le déploiement terminé.

## Ajouter une note

Les phases, les commandes et les ressources se trouvent dans [notes.js](notes.js). Ajoute à la phase concernée une commande avec un identifiant unique, un titre, le shell, la commande et une phrase expliquant son usage. Utilise des exemples génériques pour les notes publiques.
