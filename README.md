# Reconnaissance Workflow

A compact Nmap reference for authorized network reconnaissance. It includes TCP and UDP discovery, service identification, and expandable advanced checks. Commands are copyable and searchable with Ctrl+K or Cmd+K.

## Getting started

Download or clone the repository and open `index.html` in a browser. Replace placeholders such as `<local IP address>` with values from your authorized environment before running a command.

## Project structure

The site uses HTML, CSS, and vanilla JavaScript. `notes.js` holds the reconnaissance workflow and reference, `app.js` handles navigation and interaction, and `styles.css` defines the layout. [DM Sans license](assets/OFL-DM-Sans.txt)

Use this reference only on systems you own or have explicit permission to assess.
